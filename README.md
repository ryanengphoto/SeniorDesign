# Senior Design

Team project repo. Keep source and docs here; generated files stay out via `.gitignore`. Folder map: [`MAP.md`](MAP.md).

## Getting started

```bash
git clone git@github.com:ryanengphoto/SeniorDesign.git
cd SeniorDesign
```

Add files in the folders above, then commit. Empty folders are held in git with a `.gitkeep` file — you can delete that once real files are in the folder.
